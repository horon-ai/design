## Change

Added `.github/workflows/ci.yml` only. It runs on `push` (main) and `pull_request`,
sets up Bun 1.4.2 (`oven-sh/setup-bun@v2`), and runs install, lint, typecheck,
test, build. No deploy step, no secrets.

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  ci:
    name: lint / typecheck / test / build
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Bun
        uses: oven-sh/setup-bun@v2
        with:
          bun-version: 1.4.2

      - name: Install dependencies
        run: bun install --frozen-lockfile

      - name: Lint
        run: bun run lint

      - name: Typecheck
        run: bun run typecheck

      - name: Test
        run: bun test

      - name: Build
        run: bun run build
```
